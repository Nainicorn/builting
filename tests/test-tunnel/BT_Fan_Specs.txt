BEGGARS TOMB — FAN SPECIFICATIONS AND NAME MAPPING
====================================================
This file maps VentSim fan names (used in .vsm and PDFs) to the
correct IFC/Revit family names from BT_07.ifc. Use these exact
specs for fan generation. The PDF spec sheets (AC_Fan.pdf,
Diesel_Exhuast_Fan.pdf, Shaft_Fan.pdf) contain additional
manufacturer data — consult them for physical dimensions only.

------------------------

  9500 CFM → 152.4mm outlet → 15° rect-to-round transition → 500mm main duct
